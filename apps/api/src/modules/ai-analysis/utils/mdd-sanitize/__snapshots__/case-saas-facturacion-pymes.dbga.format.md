Competidores: Facturama, con API y panel sencillo para PyMEs y planes por timbre, pero menos flexible cuando un contador administra muchas empresas; Factura.com, fuerte en integración para desarrolladores pero complejo para usuarios no técnicos; y CONTPAQi Comercial, de escritorio, con larga base instalada y sin operación multiempresa en la nube. Brechas: contadores que administran varias empresas desde una sola cuenta, reintento automático cuando el PAC está caído sin riesgo de folio duplicado, y bitácora de cambios exportable para auditoría externa. Fuera de alcance en esta fase: nómina, contabilidad completa y comercio exterior. Alternativa a evaluar: vender como complemento de los sistemas de punto de venta existentes mediante API.
