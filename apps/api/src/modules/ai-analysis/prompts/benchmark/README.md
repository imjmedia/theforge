# AI Analysis / Prompts / Benchmark

Templates de prompt para los agentes del grafo DBGA (Fase 0 — Deep Research).

- **`scout-prompt.md`** — agente Scout: exploración e investigación inicial.
- **`auditor-prompt.md`** — agente Auditor: evaluación de calidad de documentación.
- **`critic-prompt.md`** — agente Critic: decisión de ruteo (continuar o sintetizar).
- **`synthesis-prompt.md`** — agente Synthesis: síntesis final del DBGA.
