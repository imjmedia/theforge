# Engine (SDD)

- **`mdd-markdown-parser.ts`:** `normalizeMddContent` / `parseMarkdownMdd` producen JSON compatible con `mddJsonSchema` (incluye **`constitution`**: señales «Constitución Cursor» desde §1–§2–§5 para el semáforo HIGH cuando Fase B fusione puertas con `sddDomainGraphOk`). Tests: `mdd-markdown-parser.constitution.spec.ts`.
- **`semaphore.service.ts`:** degradadores puros (Figma, Constitución Cursor) en rutas legacy/composite; **no** escribe `Stage.status` (ver `StageSemaphoreSyncService` + núcleo `shared-types/semaphore`).
- **`mdd-coherence/`** – `MddCoherenceService`: evalúa tablas/endpoints/huérfanos desde markdown §3/§4. `generation-status` usa evaluación **en vivo** (sin bloquear por huella persistida).
- **`mdd-update-pipeline.service.ts`:** valida/sanitiza MDD y evalúa coherencia §3/§4 vía `MddCoherenceService` antes del semáforo cuando hay `projectId`/`stageId` y complejidad HIGH.
- **Costes / conformidad:** `cost-calculator.service.ts` delega en `computeCostEstimation` (`@theforge/business-rules`); conteos con `countCostDrivers`. `conformance-gaps.util.ts` re-exporta gaps para el núcleo; `conformance.service.ts` y reparadores Blueprint/API.
- **Auditoría MDD determinística:** `mdd-internal-audit.util.ts` (paridad SQL/Mermaid, trazabilidad MFA) — compartido con el nodo Auditor y `EstimationService`.
- **Cabecera de documentos:** `document-date-header.util.ts` — `prependDocumentTimestamps` antepone en cada persistencia de markdown `Creado` y `Última regeneración` con fecha y hora completas (segundos, UTC) más comentario HTML `theforge-doc:created|updated`. Aplicado en entregables SDD (`stage-deliverable-persist`), MDD/BRD/DBGA (`projects.service`), change spec, pantallas MCP y legacy BRD.
- **Cascada SDD cross-artifact:** `sdd-cross-artifact.util.ts` (Spec↔MDD, HU↔UC, Tasks↔Blueprint/API); `phase0-brd-spec-bridge.util.ts` (Phase0→BRD→Spec en greenfield). Consumidos por `SddIntegrationService.analyzeArtifacts`.
- **Exactitud cascada ≥90 (PLAN-CASCADE-90-ACCURACY):** `domain-inventory.util.ts` (capacidades BRD, CrudMatrix, ProcessInventory, auth-skew); `cascade-accuracy.util.ts` (DocAccuracyScore / TaskAccuracyScore). Wired en analyze + delivery gate (con BRD) + hard gate export (`REQUIRE_DOC_ACCURACY_90=true`).
- **P0–P2 (0.14.0):** `domain-inventory-persist.util.ts` (`Stage.domainInventory`); `compose-section3-from-inventory.util.ts` (stubs §3, omite entidades ya definidas en prosa §3); `mdd-quality-audit.util.ts` (`removeThinSqlStubsWhenProseRich`, `entityHasRichProseInSection3`); task auditor dominio; aliases C1/T1.
- **MDD SSOT (v1.6+):** `domain-inventory-conformance.util.ts`, `mdd-ssot-repair.util.ts`, `api-prefix-unify.util.ts`, **`api-conformance-repair.util.ts`** (`reconcileApiContractsToMdd` — tabla API = §4 sin extras), **`deliverable-conformance-enforce.util.ts`** (pase determinista post-cascada), **`logic-flows-conformance-repair.util.ts`**, `entity-api-trace.util.ts`, etc. Wired en delivery gate, W4 cascada, generadores y `collectConformanceGaps`.
- **Readiness compuesto (v1.7+):** `brd-mdd-pre-patch.util.ts` (pre-parche BRD→MDD §1/§5 antes del pipeline); `domain-inventory-reconciler.util.ts` (reconcilia inventario + stubs §4); `project-semaphore-composite.util.ts` (semáforo + conformance + gaps + BRD trace); `low-medium-readiness.util.ts` (paridad LOW/MEDIUM: HU↔Tasks, Spec↔API↔UX, presencia de entregables); convergencia post-cascada en `deliverables-cascade.service.ts` (`runCascadeConvergenceLoop`, máx. 3 iteraciones; routing por `complexity`).
- **Mermaid en el pipeline MDD (`mdd-pre-render.ts`, `mdd-quality-audit.util.ts`):** `mermaidBlockHasUsableStructure` exige una cabecera reconocida (la arista solo en flowchart y graph; erDiagram exige entidad o relación). `repairPrematureMermaidFenceClose` siempre emite el cierre del fence; `readMermaidFenceBody` termina un fence sin cerrar en el siguiente fence con lenguaje sin consumirlo, y `resolveReassembledFenceLines` reensambla las líneas huérfanas. `stripInvalidMermaidFences` degrada a prosa solo un cuerpo sin cabecera. `sanitizeMermaidBlock` ya no llama a `ensureErDiagramHeader`. `detectBareMermaidBlocks` ignora las líneas dentro de fences. La garantía en CI está en `apps/api/src/modules/mermaid-oracle/README.md`.
